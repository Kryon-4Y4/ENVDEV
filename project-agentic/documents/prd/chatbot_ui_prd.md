# ENVDEV Chatbot Web UI - MVP PRD

## 1. 产品概述 (Elevator Pitch)

ENVDEV Chatbot Web UI 是一个面向 AI 学习者和开发者的智能对话界面，通过科技感十足的深色主题设计，提供沉浸式的 AI 交互体验。用户可以与 DeepSeek 大模型进行流畅的流式对话，体验打字机效果的实时响应。

## 2. 问题陈述 (Problem Statement)

当前的 ENVDEV Web UI 功能完整但视觉设计过于朴素：
- 浅色背景缺乏科技感与沉浸感
- 消息气泡样式单调，缺乏视觉层次
- 没有体现 AI/科技产品的现代审美
- 缺少暗色模式支持，长时间使用易疲劳

目标用户（AI 学习者、开发者）期望一个更专业、更具科技感的对话界面。

## 3. 目标用户 (Target Audience)

| 用户类型 | 描述 | 核心需求 |
|---------|------|---------|
| AI 学习者 | 学习 Agentic AI 开发的学生和爱好者 | 清晰的对话展示，便于学习内容 |
| 前端开发者 | 希望参考 UI 实现的开发者 | 代码结构清晰，样式可定制 |
| 长时间用户 | 需要长时间与 AI 对话的用户 | 护眼深色主题，舒适的视觉体验 |

## 4. 独特卖点 (USP)

- **科技感深色主题**：赛博朋克风格的配色，让对话体验更具未来感
- **流式打字机效果**：实时展示 AI 思考过程，增强交互感
- **极简专注设计**：去除干扰元素，让用户专注于对话内容本身

## 5. 平台目标

- **Web 端**（主要）：现代浏览器（Chrome、Firefox、Safari、Edge）
- **响应式设计**：适配桌面和平板设备

## 7. UX/UI 设计考虑

### 7.1 整体布局

```
┌─────────────────────────────────────────────────────────────┐
│  Header: Logo + 标题 + 状态指示器                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│                                                             │
│                    对话消息区域                               │
│              (滚动区域，最大宽度限制)                           │
│                                                             │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│  输入区域: 输入框 + 发送按钮                                   │
└─────────────────────────────────────────────────────────────┘
```

### 7.2 各屏幕/组件设计要点

#### Header 区域
- 固定顶部，半透明毛玻璃效果
- 左侧：Logo 图标 + 产品名称
- 右侧：连接状态指示（绿色脉冲点）
- 高度：约 56-64px

#### 对话消息区域
- 占据主要空间，可滚动
- 消息最大宽度 720px，居中显示
- 用户消息：右对齐，主色调背景
- AI 消息：左对齐，深色卡片背景
- 消息间有适当间距
- 新消息自动滚动到底部

#### 输入区域
- 固定底部
- 输入框：圆角，深色背景，聚焦时边框发光
- 发送按钮：主色调，hover 时发光效果
- 等待回复时按钮禁用，显示加载状态

#### 空状态
- 无消息时显示欢迎界面
- 中央显示 Logo + 欢迎语
- 可选：显示几个快捷提问建议

### 7.3 交互细节

| 交互 | 描述 |
|------|------|
| 发送消息 | 回车发送，Shift+回车换行 |
| 等待状态 | 发送后输入框禁用，按钮显示加载动画 |
| 流式输出 | AI 回复逐字显示，带光标闪烁效果 |
| 自动滚动 | 新内容出现时自动滚动到底部 |
| 错误提示 | 请求失败时在消息区显示错误卡片 |

## 8. 技术约束

- **框架**：React 19 + Vite
- **样式**：CSS Modules 或 Tailwind CSS（待确认）
- **图标**：Lucide React
- **后端 API**：已有 `/api/chat/stream` SSE 接口
- **无需修改后端**：仅前端 UI 改造

## 9. 成功指标

- 页面加载时间 < 1s
- 流式输出流畅无卡顿
- 在主流浏览器中表现一致
- 用户主观评价：科技感强、视觉舒适
